# Análise de Dados - E-Commerce Olist

Análise exploratória e estatística do dataset público da Olist, abrangendo pedidos realizados no mercado brasileiro de e-commerce entre 2016 e 2018.

## Sobre o Projeto

Este projeto demonstra um pipeline completo de análise de dados, desde a limpeza e exploração até a geração de insights estratégicos e visualização interativa. O dataset contém informações de aproximadamente 100 mil pedidos, incluindo dados de clientes, produtos, pagamentos, avaliações e logística.

## Objetivos

- Realizar análise exploratória para compreender padrões de comportamento no e-commerce
- Investigar fatores que influenciam a satisfação do cliente
- Identificar relações entre tempo de entrega e avaliações
- Demonstrar domínio em Python, SQL e Power BI aplicados à análise de dados

## Ferramentas e Tecnologias

- **Python** - Pandas, NumPy, Matplotlib, Seaborn, SciPy
- **SQL** - Queries demonstrativas em sintaxe MySQL
- **Power BI** - Dashboard para visualização
- **Google Colab** - Ambiente de desenvolvimento

## Análises Realizadas

### Análise Exploratória
- Distribuição geográfica de pedidos por estado
- Evolução temporal do volume de vendas
- Análise de métodos de pagamento
- Comparação de tempos médios entre etapas do processo
- Avaliação do cumprimento de prazos estimados
- Relação entre avaliações e volume de pedidos

### Análise Aprofundada
- Investigação da correlação entre tempo de entrega e satisfação do cliente
- Análise da influência do valor do pedido nas avaliações
- Identificação e análise de outliers em tempo de entrega
- Testes estatísticos de significância

## Dashboard Power BI

Dashboard desenvolvido para monitoramento de satisfação do cliente e performance logística. Permite identificação de padrões regionais e gargalos operacionais através de filtros e análise multidimensional.

## Fonte dos Dados

Dataset público disponível no Kaggle: Brazilian E-Commerce Public Dataset by Olist

O dataset contém informações de 100 mil pedidos realizados entre 2016 e 2018, incluindo dados de pedidos, clientes, produtos, avaliações e pagamentos.
