# Queries SQL

Queries SQL demonstrativas das análises realizadas no projeto.

## Sobre

As queries replicam as análises exploratórias feitas em Python, demonstrando como os mesmos resultados seriam obtidos em um banco de dados relacional MySQL.

## Conteúdo

- Distribuição de pedidos por estado (TOP 15)
- Evolução temporal do volume de vendas
- Métodos de pagamento mais utilizados
- Tempo médio entre etapas do processo
- Análise de cumprimento de prazos
- Distribuição de avaliações dos clientes

As queries demonstram uso de JOINs, agregações, funções de data e cálculos percentuais.
